# Matiane / მატიანე

Редактор фотокниг A5 с английским и грузинским интерфейсом. Фотографии обрабатываются в браузере и не отправляются на сервер. Проект автоматически сохраняется в IndexedDB на текущем устройстве; для резервной копии используйте **Project → Download project**. Очистка данных браузера удалит локальный проект.

## Запуск

Требуется Node.js 22 или новее. Проверено на Node.js 24.19.0.

Распакуйте скачанный проект и откройте терминал в папке, где лежит `package.json`. Выполните:

```sh
npm ci
npm run dev -- --port 5173
```

Откройте в браузере адрес, который терминал покажет рядом с `Local`. Оставьте терминал открытым во время работы. Для остановки нажмите Ctrl+C. В облачном окружении папка проекта — `/workspace/matiane`.

Для production-сборки: `npm run build`. Каталог `dist/` можно разместить на статическом хостинге с HTTPS. Для локальной проверки сборки: `npm run preview -- --port 4173`.

## Установка на Ubuntu VPS

Подключитесь по SSH к новому VPS под пользователем `ubuntu`. У него должны быть права `sudo`. Команда ниже загружает установщик из этого репозитория; его содержимое доступно для просмотра в `deploy/install-ubuntu.sh`.

```sh
curl -fSL https://raw.githubusercontent.com/emouhvarivahtang-jpg/matiane/main/deploy/install-ubuntu.sh -o /tmp/matiane-install.sh && bash /tmp/matiane-install.sh
```

По умолчанию сайт обслуживается по HTTP на `57.129.177.67`. Для другого IP или домена передайте его аргументом: `bash /tmp/matiane-install.sh example.com`. HTTPS в эту первоначальную установку не входит.

Установщик устанавливает Nginx через подписанные пакеты Ubuntu и отдельный Node.js 24 из официального архива с проверкой SHA-256. Затем клонирует проект в `/opt/matiane/source`, собирает его и публикует через `/var/www/matiane/current`. Проверяется соответствие отданного HTML, JS и грузинского шрифта файлам сборки. Повторный запуск обновляет чистый checkout; локальные изменения блокируют обновление. Другие сайты Nginx и системный Node.js не заменяются. Если UFW уже включён, добавляется разрешение HTTP на порт 80; сам брандмауэр не включается.

После установки откройте сайт в браузере и проверьте загрузку фотографий, сохранение после обновления страницы и скачивание PDF. Для публичного использования настройте HTTPS. Локальные проекты привязаны к адресу сайта: при переходе с HTTP/IP на HTTPS/домен перенесите их через Download project / Open project.

## Как собрать книгу

1. Загрузите JPG, PNG или WebP. Максимум 30 MB на файл и 200 фотографий в книге. Очень большие изображения уменьшаются до 5000 пикселей по длинной стороне; ориентация EXIF учитывается. JPEG сохраняется с качеством 95%.
2. Выберите страницу и макет. Нажмите на рамку, затем на фотографию в библиотеке; также доступно перетаскивание. Слайдеры положения кадрируют фотографии на выбранной странице.
3. Выберите цвет бумаги. На вкладке Caption добавьте английскую или грузинскую подпись, задайте стиль, размер и выравнивание.
4. Добавляйте, дублируйте, переставляйте и удаляйте страницы. Максимум 80 страниц. Undo/Redo хранит последние 30 операций в текущем сеансе.
5. Проверьте Preview и нажмите Export book. Пустые рамки и фотографии ниже 150 DPI требуют явного подтверждения перед экспортом. Для качественной печати рекомендуется 300 DPI.

Сервис открывается с шестью демонстрационными страницами. Демофотографии имеют низкое разрешение и предназначены для знакомства с редактором. **Project → New book** создаёт пустую книгу. Название в верхней панели редактируется; язык интерфейса не меняет пользовательский текст.

## Печатный файл

- Один PDF, отдельные вертикальные страницы, порядок совпадает с редактором.
- Без вылетов: MediaBox и TrimBox 148 × 210 мм.
- С вылетами: MediaBox/BleedBox 154 × 216 мм; TrimBox 148 × 210 мм, отступ 3 мм со всех сторон. Фон и полноформатная фотография продолжаются в область вылетов.
- Текст остаётся текстом; шрифты Noto Sans, Noto Serif и Noto Sans Georgian встроены в PDF. Длинные подписи уменьшаются до размера, который помещается в блок текста.
- Изображения в RGB. Это обычный PDF, не PDF/X и не CMYK. Требования цветового профиля, PDF/X, спуска полос, переплёта, корешка и отдельной обложки необходимо согласовать с конкретной типографией. Метки реза не добавляются; зона обрезки указана в TrimBox.
- При печати используйте масштаб 100%.

Аккаунты, оплата, заказ печати и облачное хранение в эту первую версию не входят. Для работы приложения не нужны ключи API или внешние сервисы; шрифты и демонстрационные фотографии поставляются локально.

## Проверки

```sh
npm test
npx playwright test --workers=2
npm run build
```

Браузерные тесты используют установленный `/usr/bin/chromium`. В другой среде измените `executablePath` в `playwright.config.js` на путь к Chromium либо установите браузер через Playwright и уберите это поле. Сценарии проверяют загрузку фотографий, языки, сохранение после перезагрузки, макеты, операции со страницами, импорт/экспорт проекта, PDF и мобильную ширину.
